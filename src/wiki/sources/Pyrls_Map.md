# How to Use Pyrls in This Residency

Pyrls (app.pyrls.com) sections, as seen on your account:
- **Drug Summaries** (800+): key charts and tables per drug. Use for the fast "what do I need to know" check.
- **AHFS Drug Information** (1,700+ monographs): the full monograph when you need depth.
- **Pharmacotherapy reviews:** disease state reviews (for example ischemic stroke, hospital acquired pneumonia, diabetes). Read the matching review when you start each module.
- **Guidelines Database:** find the current guideline for each module and drop the PDF or link in `raw/`.
- **Charts and Tables** (for example beta lactam cross reactivity): print the ones you use on shift.
- **Calculators** and **Drug Interactions.**
- **Your Library:** upload St. Mary's protocols you are allowed to keep, and your own notes. Do not upload anything with patient information.

## Per module
| Module | Pyrls first stop |
|---|---|
| L&D | Guidelines Database: hypertension in pregnancy, PPH, GBS; drug summaries for magnesium sulfate, oxytocin |
| NICU | Drug summaries: gentamicin, ampicillin, caffeine; pediatric dosing tables |
| PICU | Charts and Tables for pediatric emergency doses; status epilepticus guideline |
| Stroke | Ischemic Stroke Pharmacotherapy Review |
| ID | Beta Lactam Cross Reactivity chart; HAP/VAP and CAP reviews |

Use Lexicomp Pediatric and Neofax (if St. Mary's has them) as the dosing reference for neonates. Pyrls is a great review tool; the hospital's references and order sets are what you verify against.
