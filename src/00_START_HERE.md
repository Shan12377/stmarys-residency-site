# START HERE: St. Mary's Virtual Residency

## What this is
A residency you run yourself. It follows the four ASHP PGY1 competency areas (patient care, practice advancement, leadership, teaching) and is built around what St. Mary's actually sees: trauma, stroke, NICU, PICU, Labor & Delivery, adult critical care and the IV room.

## How to pick back up in a new chat
Open a new chat in the RxCareer-Agent project and paste:

> Open my St. Mary's Virtual Residency folder (Documents/St Marys Virtual Residency). Read CLAUDE.md, index.md and the last entries in log.md, then continue with the next module in the 12 week plan.

## Folder map
- `CLAUDE.md`: the rules Claude follows in this folder.
- `index.md`: every page, one line each.
- `log.md`: what was added and when.
- `raw/`: drop anything here (guideline PDFs, St. Mary's policies, order sets, your own notes, Pyrls PDFs). Claude reads it and updates the wiki.
- `wiki/curriculum/`: the 12 week plan and daily routine.
- `wiki/st-marys/`: how leadership thinks, service lines.
- `wiki/sources/`: where to stay current, and how to use Pyrls.
- `wiki/clinical/`: the modules.
- `wiki/cases/`: practice cases with model answers.

## Best way to use Obsidian
Open this folder as a vault in Obsidian. The [[links]] become clickable, and the graph view shows how topics connect.

## Your three habits
1. **Daily (20 min):** one case from `wiki/cases/`, out loud, timed.
2. **Weekly (2 hours):** one module from the plan, plus one ISMP alert and one new FDA safety communication.
3. **Every shift:** write down one question you couldn't answer in 30 seconds. Drop it in `raw/questions.md`. Claude turns it into a wiki page.
